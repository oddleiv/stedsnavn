Stedsnavn

Versjon 2: med tidsavbrudd, så siden ikke blir stående fast.

Vis lokalt navn for posisjonen din. Appen prøver først navngitte OSM-flater, deretter Kartverket/SSR og Nominatim.

GPS krever at siden åpnes via https, slik som GitHub Pages.

Prioritet

  1. Navngitte flater som punktet ligger inni, f.eks. neighbourhood, suburb, quarter, park.
  2. Offisielle stedsnavn fra Kartverket/SSR nær posisjonen.
  3. Nominatim/adresse som fallback.
